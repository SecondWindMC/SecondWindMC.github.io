Paper revive plugin for SMP servers

SecondWind adds a downed-but-not-out state to Paper 1.21.x servers. Instead of instantly dying, players collapse, crawl, bleed out, and wait for a teammate — or get executed by an enemy.

What the plugin changes

  • Lethal damage creates a timed downed state instead of immediate death.
  • Teammates revive by holding sneak near the downed player.
  • Enemies can use the same channel to execute.
  • Combat logging while downed counts as a real death.
  • Commands such as home, spawn, back, warp, and teleport acceptance can be blocked while downed.

Why server owners install it

SMP tension: fights end with rescue attempts, cover fire, and hard choices instead of instant death screens.
Lifesteal compatibility: downing is not death, so hearts and death-based mechanics trigger only after bleed-out or execution.
Factions control: team-only revives, executor rules, movement speed, radii, timers, exempt damage causes, and blocked commands are configurable.

Install

1. Download SecondWind for Paper 1.21.x.
2. Put the jar in plugins/.
3. Restart the server.
4. Edit plugins/SecondWind/config.yml.
5. Run /sw reload.

The plugin has zero dependencies and was validated on Paper 1.21.11 with automated client-bot death, restart, and recovery tests.
