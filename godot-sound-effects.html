Import

How to use the sounds in Godot

  1. Download the zip file.
  2. Extract the zip into your Godot project root so the files land in addons/circuit_ui_sfx_free_sample/audio/.
  3. Add an AudioStreamPlayer node where the feedback should happen.
  4. Load a WAV file as the stream, or call it from GDScript: $AudioStreamPlayer.stream = load("res://addons/circuit_ui_sfx_free_sample/audio/ui-click-01.wav"), then play().
