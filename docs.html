Configuration reference

Server docs

Every key in both plugins' config.yml, and what it changes. Defaults shown ship in the jar — drop it in plugins/, start the server, edit, restart or /sw reload.

SecondWind — config.yml

KeyDefaultWhat it does
downed-health4.0Health a downed player keeps (half-hearts ×2 — 4.0 = 2 hearts).
revived-health6.0Health restored when the revive completes.
bleed-out-seconds60Time on the ground before a downed player dies for real.
revive-seconds8Channel time to revive (sneak-hold, in range).
execute-seconds10Channel time for an enemy to execute.
interact-radius3.0Max distance (blocks) for revive/execute.
movement-multiplier0.15Crawl speed as a fraction of walk speed; 0 = immobile.
post-revive-invulnerable-seconds5Grace period after being revived.
bossbar-visible-radius16How far the bleed-out boss bar is visible.
reviversANYONEANYONE or TEAM (same scoreboard team).
executorsENEMYENEMY, ANYONE, or NONE.
channel-interrupt-on-damagetrueDamage breaks an in-progress revive/execute.
allow-crawltruefalse = downed players can't move at all.
kill-on-logouttrueCombat-logging while downed = real death.
broadcast-on-downtrueAnnounces "<player> is down!" in chat.
exempt-causesVOID, SUICIDE, WORLD_BORDER, CUSTOM, GENERIC_KILL, KILLDamage causes that kill outright instead of downing.
disabled-worlds[]Worlds where normal death applies.
blocked-commandsspawn, home, tpa, tpaccept, tpahere, warp, backCommands a downed player can't run.
debugfalseVerbose console logging.

Admin commands

/sw down <player>     force a player into the downed state
/sw revive <player>   instantly revive
/sw execute <player>  instantly execute
/sw status          show all currently downed players
/sw reload          reload config.yml + messages.yml

GraveGuard — config.yml

KeyDefaultWhat it does
protection-seconds120Time only the owner (and ops) can open the grave.
despawn-seconds600Until the grave despawns entirely (0 = never).
max-search-height8Blocks searched upward from the death point to place the grave.
hologramtrueFloating owner + countdown text above the grave.
store-xptruePlayer XP is stored in the grave too.
return-compasstrueGive the owner a "Last Grave" compass on respawn.
messages.*—Every chat line is editable, with %time%/%owner%/%loc% placeholders.
prefix[&6GraveGuard&8]Chat message prefix (color codes supported).
Compatibility: both plugins target Paper 1.21.x (tested 1.21.4 & 1.21.11), Java 21, zero dependencies. They run fine side by side — SecondWind handles the down; if the player still dies, GraveGuard guards the loot.
